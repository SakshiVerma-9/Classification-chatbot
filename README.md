# 🤖 ML Chatbot Project

## 📌 Overview
This project is a Machine Learning-based chatbot developed using Python. It predicts the most appropriate response to a user's query using Natural Language Processing (NLP) and a trained machine learning model.

---
## 🌐 Live Demo

**Deployment Link:** https://ml-chatbot-project-xjmhwvkthycdewhgsrnpk2.streamlit.app/

## 🚀 Features
- Interactive chatbot interface
- NLP-based text preprocessing
- TF-IDF Vectorization
- Machine Learning model for response prediction
- Fast and easy to use

---

## 🛠️ Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- NLTK
- Pickle
- Streamlit

## 📊 Dataset
The chatbot is trained using the `sakshi.csv` dataset, which contains user queries and corresponding responses.

---

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/SakshiVerma-9/ML-Chatbot-Project.git
```

2. Move into the project folder

```bash
cd ML-Chatbot-Project
```

3. Install the required libraries

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
streamlit run app.py
```

---

## 📸 Output
The chatbot accepts user input and predicts the most suitable response using the trained machine learning model.
